# Product

## Register

product

The application is a single-user SEO tool. Its public website in `site/` uses
the brand register: explain the product, show real screens, and help visitors
choose a supported installation method.

## Users

Site owners and operators who want their Search Console, GA4, crawler, and
PageSpeed data in one local application. The application supports Turkish and
English; the public website also has German, French, Italian, and Portuguese
editions.

## Product Purpose

Make free Google data and actionable site findings understandable on the user's
own computer. Windows has an installer; Mac and Linux use Docker. The website
must describe shipped capabilities accurately and distinguish planned work.

## Brand Personality

Direct, practical, and transparent. Explain what the software does in plain
language. Preserve the seowatcher identity and its warm dark palette with an
ember orange accent, as documented in CLAUDE.md and the existing stylesheets.

## Anti-references

Avoid invented usage statistics, paid-data promises, fake product screenshots,
decorative motion that delays content, and interfaces that hide information
from keyboard or reduced-motion users.

## Design Principles

- Show the actual application and its supported workflows.
- Keep download and installation paths easy to find.
- Prefer readable content and quick interaction over decoration.
- Preserve page URLs, language parity, and existing navigation semantics.
- Report live counts only when a complete response supports them.

## Accessibility & Inclusion

Preserve semantic headings, visible focus, keyboard navigation, readable
contrast, and operating-system reduced-motion preferences. Test mobile reflow
and long translations. Automated accessibility results supplement browser
checks; they do not establish complete WCAG conformance.
