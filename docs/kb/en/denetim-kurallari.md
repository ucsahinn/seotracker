The audit applies 202 rules: 13 critical, 93 warnings and 96 info. Each rule ID registered in the app has exactly one row below.

- **Critical** (13 rules): Google cannot see or understand the page, or visitors cannot reach the site. Fix these first.
- **Warning** (64 rules in the Warning table, 29 under Additional checks): issues that gradually cost rankings and clicks.
- **Info** (62 rules in the Info table, 34 under Additional checks): smaller improvements.

Severity weights the score: critical 40, warning 15, info 3, scaled by the share of pages a rule affects. See [Site audit](/docs/site-denetimi/) for how the score is calculated.

Each row gives the rule name as the app shows it, what the finding means and the first step to fix it. The finding card in the app carries the full fix text. The ID column matches the CSV export and the identifiers your assistant sees over MCP.

## Common terms

- **canonical**: a tag that names the preferred URL of a page when several addresses show the same content.
- **noindex**: a tag that hides a page from search.
- **hreflang**: the language version tag. It points to the same page in other languages.
- **meta description**: the gray summary under the title in a search result.
- **structured data** (JSON-LD): a hidden note that tells Google what the page is (a product, an article and so on). It can add extras to the search result, such as stars or an image (rich result).
- **robots.txt**: the file that tells Google which pages it may visit. A "Disallow" line forbids access.
- **sitemap**: the list of pages on your site. **lastmod**: the date the page last changed.
- **redirect**: sending visitors from one address to another.
- **user agent**: the name a browser or crawler gives itself.
- **title** (title tag): the title shown in the tab and in search. **H1**: the main heading of the page. **alt text**: a short text that says what an image shows.
- **nofollow**: a tag that says "do not follow this link". **head**: the top part of the page source.
- **LCP**: how long the main content of the page takes to appear. **CLS**: content shifting while the page loads. **INP**: how long the page takes to respond to a click.
- **Lighthouse**: Google's page-testing tool. **SSL certificate**: the document that makes your site https (a secure address).

## How the rules run

**Per-page rules** check each crawled page and list every page they affect.

**Site-wide rules** produce one finding for the whole site. The robots.txt and sitemap rules work this way, as do "Site has no social sharing tags (Open Graph)" and "Site has no structured data". A second group probes the site once at the start of the audit: www and non-www addresses, the http-to-https redirect, the response to a random address that does not exist, robots.txt blocking the whole site, its Sitemap line and AI crawlers, the site icon, llms.txt, security headers (HSTS, X-Content-Type-Options, frame protection, Referrer-Policy), and the start page's size, compression and time to first byte.

**External sources.** The SSL certificate's expiry date comes from public Certificate Transparency logs, the domain's expiry date from registration data (RDAP), and the SPF and DMARC records from DNS. "Analytics id on the pages doesn't match the connected property" compares the measurement ID found in the HTML with the web streams of the GA4 property connected to the project.

**Google rules.** Rules whose name starts with "Google" use the answers stored on the **Index status** tab, not the crawl. They run only after you have checked pages on that tab.

**Speed rules.** The LCP, CLS and INP rules, the Lighthouse SEO score and every rule whose ID starts with `lh-` read the Lighthouse report that PageSpeed Insights returns for each page. They run only when **Also measure page speed** is on, and they use the mobile measurement. A Lighthouse check that did not run or failed on a page counts as neither a finding nor a pass.

**Outgoing links and image sizes.** "A link to another site is broken" and "Image file is too large" run only when **Also check outgoing links and image sizes** is on. After the crawl, the audit requests at most 300 such addresses. Sites that block bots, such as social networks, and addresses that do not respond are never counted as broken.

A rule that an audit did not measure shows as **Not measured** on the **Checks** tab. This includes audits that ran before the rule existed.
